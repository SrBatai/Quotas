# VENTISCA — procedural 3D assets

Every model in `../assets/models/*.glb` is generated by the Python scripts in this folder with
Blender 5.0.1 used as a Python module (`import bpy`). The contract (names, pivots, axes, sizes,
materials, collision) is `../docs/ASSET_SPEC.md`.

## Rebuild

```sh
cd winter-survival/blender
python3 build_all.py          # builds all assets, then runs verify_assets.py; exit 0 = ALL OK
python3 build_cabin.py        # any single family can be rebuilt on its own
```

Each script starts from an empty scene, builds one asset at a time, saves `sources/<asset>.blend`
and exports `../assets/models/<asset>.glb` (glTF binary, +Y up, flat-shaded, palette materials only).

| Script | Assets |
|---|---|
| `build_player.py` | player |
| `build_animals.py` | wolf, deer |
| `build_trees.py` | pine_a, pine_b, pine_c, dead_tree, stump |
| `build_rocks.py` | rock_a, rock_b, rock_c, stone |
| `build_plants.py` | berry_bush |
| `build_pickups.py` | firewood, fallen_log |
| `build_fire.py` | campfire, torch, lantern |
| `build_tools.py` | stone_axe |
| `build_cabin.py` | cabin |
| `build_furniture.py` | bed, desk, chair, shelf, clock, cabinet, wood_stove |
| `build_props.py` | a_frame_cabin, pickup_truck, signpost, fence |
| `build_optional.py` | tent, storage_box |

Shared helpers: `lib/palette.py` (the only place materials are created), `lib/lowpoly.py`
(`MeshBuilder`: boxes, lofts, cylinders, jittered icospheres, snow-by-normal, pivots, parenting,
collision boxes; faces are auto-oriented outward), `lib/export.py` (scene checks, save + export,
re-import).

## Verify

```sh
python3 verify_assets.py
```

Re-imports every `.glb` and checks ASSET_SPEC §6: required node names, hierarchy, pivots (±3 cm),
forward axis (+Y Blender = −Z Godot), bounding sizes (±10 %), transforms, flat shading (corner
normals equal face normals), palette materials, closed parts wound outward, triangle budgets and the
`Col*-convcolonly` collision boxes. It prints one `OK`/`FAIL` line per asset and ends with `ALL OK`.
